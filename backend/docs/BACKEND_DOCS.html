Composition root único
src/main/container.ts é o único lugar onde dependências são instanciadas. Use cases recebem tudo via construtor (DI manual). Não criar singletons fora dali.

Boot fail-fast em PROD

Em NODE_ENV=production, o backend recusa subir se:

  • JWT secrets fracos / iguais / < 32 chars
  • CORS_ORIGIN=* ou contém http:// (exceto localhost)
  • EMAIL_PROVIDER=smtp sem SMTP_HOST/USER/PASS
  • Triggers de imutabilidade do audit não aplicados
  • Cert ICP-Brasil ausente quando TFD_SIGN_REQUIRED=true

Hash chain TFD (TJ-compliant)

Cada linha em tfd_audit_log tem hash = SHA-256(payload | hashAnterior) onde hashAnterior é o último hash da prefeitura:

const payload = [
  registro.id, registro.acao, registro.recursoId,
  registro.operadorId, registro.ip, registro.em.toISOString(),
  JSON.stringify(registro.antes ?? null),
  JSON.stringify(registro.depois ?? null),
  hashAnterior,
].join('|');
return crypto.createHash('sha256').update(payload).digest('hex');

Genesis: '0' × 64. Verificação via verificarCadeiaTfd(prefeituraId) re-calcula toda a cadeia e reporta corrompidos. Inserção serializada por prefeitura via SELECT FOR UPDATE (v0.17.1).

Validações de entrada

  • CPF checksum: isCpfValido() mod-11 + bloqueia triviais (000.000.000-00, etc.)
  • Senha forte: validarSenhaForte() bloqueia < 8 chars, numérica pura, sequências comuns, CPF como senha
  • Email: regex + ≤180 chars + lowercase
  • HTTPS-only em URLs de banners (imagemUrl, ctaUrl) — Android bloqueia HTTP por padrão
  • Lat/Lng: range [-90,90]/[-180,180] + cross-validation (ambos ou nenhum)
  • Horários: JSON estruturado com regex HH:MM + abre < fecha

Sanitização anti-XSS

shared/sanitizeText.ts aplicado em texto livre de banners, dossiê, recomendações:

  • Strip HTML tags (<script>, <img onerror>)
  • Strip control chars + zero-width Unicode (anti smuggle)
  • Normaliza CRLF → LF
  • Trim + cap 4000 chars (anti DoS)

Anti-enumeration

  • 404 ao invés de 403 em recursos fora de escopo (não vaza existência)
  • Timing-constant no esqueci-senha: MIN_MS = 120 + bcrypt.compare dummy quando CPF não existe
  • Resposta genérica 204 sempre em esqueci-senha (sucesso ou silencioso)

Path traversal guard

Download de anexos usa path.relative(uploadDir, candidato) + checagem ../absolute path. Tentativa de escape → audit crítico DOWNLOAD_ANEXO_PACIENTE_PATH_TRAVERSAL.

Content-Disposition RFC 5987 / 6266

buildContentDisposition() emite duas formas: ASCII fallback (filename="...") + UTF-8 percent-encoded (filename*=UTF-8''...). Strip de CR/LF (anti header injection).

Race conditions fechadas

E.1 · PushDispatcherWorker · estratégia de retry

  • Batch size 50 notificações pushStatus=PENDENTE por tick.
  • Backoff exponencial em minutos: [0, 1, 5, 30] — máx 4 tentativas.
  • Após esgotar → status EXCEDIDO (dead-letter — alerta op).
  • Sem dispositivo cadastrado → SEM_DEVICE (não-retry).
  • Falha permanente (endpoint 410/404 do ntfy) → remove device + status FALHOU.
  • Fallback por email para tipos críticos: APROVADO, REJEITADO, AGENDADO, PENDENCIA_REGISTRADA, RESPOSTA_SUS_DISPONIVEL.
  • Audit por evento: PUSH_ENVIADO_OK, PUSH_TENTATIVA_FALHOU, PUSH_EXCEDIDO, PUSH_DEVICE_REMOVIDO_FALHA_PERMANENTE.

H.4 · Geração da assinatura

export function assinarConteudoTj(conteudo: Buffer): AssinaturaResult {
  const sha256 = crypto.createHash('sha256').update(conteudo).digest('hex');

  // Sem cert → HASH_ONLY
  if (!cert) return { modo: 'HASH_ONLY', sha256 };

  // PKCS#7 detached signed data
  const p7 = forge.pkcs7.createSignedData();
  p7.content = forge.util.createBuffer(conteudo.toString('binary'));
  p7.addCertificate(cert);

  p7.addSigner({
    key: privateKey,
    certificate: cert,
    digestAlgorithm: forge.pki.oids['sha256'],
    authenticatedAttributes: [
      { type: forge.pki.oids['contentType'], value: forge.pki.oids['data'] },
      { type: forge.pki.oids['messageDigest'] },        // auto-calc
      { type: forge.pki.oids['signingTime'], value: new Date() },
    ],
  });
  p7.sign({ detached: true });        // ← DETACHED (ZIP continua válido)

  return {
    modo: 'ICP_BRASIL',
    sha256,
    pkcs7DerBase64: Buffer.from(forge.asn1.toDer(p7.toAsn1()).getBytes(), 'binary').toString('base64'),
    certPem: forge.pki.certificateToPem(cert),
    certSubject: 'CN=PREFEITURA ÁGUAS BELAS,...,O=ICP-Brasil,...',
    certValidoAte: cert.validity.notAfter.toISOString(),
  };
}

J.4 · Tratamento de erro tipado

try {
  await api.login(cpf: '123.456.789-00', senha: '12345678');
} on DioException catch (e) {
  final err = e.error;
  if (err is UnisismApiError) {
    // err.code é SCREAMING_SNAKE_CASE — fonte de verdade pra UX
    switch (err.code) {
      case 'CREDENCIAIS_INVALIDAS':
        mostrarErro('CPF ou senha inválidos');
      case 'CONTA_NAO_ATIVADA':
        navegarPara('/ativar');
      case 'RATE_LIMIT':
        mostrarErro('Tente novamente em alguns minutos');
      case 'USUARIO_BLOQUEADO':
        mostrarErro('Conta bloqueada por 30 min após 5 tentativas');
      default:
        mostrarErro(err.message); // fallback ao text pt-BR do backend
    }
  }
}

J.5 · Persistência segura do token

// SecureTokenStorage — criptografia at-rest no device
// Android: EncryptedSharedPreferences (AES-256 GCM via Tink)
// iOS:     Keychain Services (kSecAttrAccessibleWhenUnlockedThisDeviceOnly)
class SecureTokenStorage implements TokenStorage {
  static const _key = 'unisism_paciente_token';
  final _storage = const FlutterSecureStorage();

  @override
  Future<String?> read() => _storage.read(key: _key);

  @override
  Future<void> write(String? token) => token == null
      ? _storage.delete(key: _key)
      : _storage.write(key: _key, value: token);
}

J.6 · Download de anexo (binary stream)

Future<void> baixarEAbrir(String anexoId) async {
  final dl = await api.baixarAnexo(anexoId);
  // dl.bytes (Uint8List), dl.filename, dl.mimeType, dl.sha256

  // Salvar em local storage
  final dir = await getApplicationDocumentsDirectory();
  final path = '${dir.path}/${dl.filename}';
  await File(path).writeAsBytes(dl.bytes);

  // Validar SHA-256 (defensivo — backend já enviou correto)
  final hash = sha256.convert(dl.bytes).toString();
  assert(hash == dl.sha256, 'corrupção em trânsito');

  // Abrir no visualizador nativo
  await OpenFilex.open(path);
}
