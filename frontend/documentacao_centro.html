UNISISM · Centro de Especialidades (Fase 1: Recepção)

Guia de Integração e Regras do Algoritmo Backend - v1.1.0

1. Visão Geral do Módulo

O módulo Centro de Especialidades Municipal gerencia a jornada secundária do paciente após a regulação da Secretaria Municipal de Saúde (SMS). A Fase 1: Recepção gerencia os agendamentos das consultas e exames especializados.

Fluxo de Estados: [UBS: RASCUNHO] → [SMS: AGUARDANDO_REGULACAO] → [SMS: APROVADO com filaDestino: CENTRO_ESPECIALIDADES] → [CENTRO: agendamentoPrevisto setado].

2. Algoritmo de Otimização de Vagas (Backend) REQUISITO

A recepção do Centro não escolhe a data ou hora da consulta manualmente. Esse controle foi removido do frontend para evitar favorecimentos e otimizar a fila clínica de forma impessoal.

Regras para desenvolvimento do algoritmo no Backend:

  1. Classificação Clínico-Temporal (Prioridade): Pacientes em estados mais críticos (EMERGENCIA e URGENTE) devem ter preferência absoluta na fila, recebendo as vagas mais próximas possíveis da escala de trabalho do médico.
  2. Escala de Trabalho dos Médicos: O algoritmo deve mapear os dias e turnos de trabalho de cada especialista solicitado (ex: segundas e quartas, das 08h às 12h) e preencher sequencialmente as vagas vagas/slots livres.
  3. Tratamento na API: Ao receber o agendamento (tanto via Fila da Regulação quanto via Balcão), o backend roda o algoritmo de otimização de vagas, agenda o paciente e retorna a data calculada (agendamentoPrevisto) e o horário nos detalhes do agendamento.

3. Endpoints Requeridos / Consumidos

GET /encaminhamentos?status=APROVADO&limit=1000

Retorna os encaminhamentos aprovados pela regulação. O frontend filtra no cliente por filaDestino === 'CENTRO_ESPECIALIDADES'.

{
  "encaminhamentos": [
    {
      "id": "uuid-1234",
      "protocolo": "ENC20260721-001",
      "status": "APROVADO",
      "filaDestino": "CENTRO_ESPECIALIDADES",
      "agendamentoPrevisto": null,
      "paciente": {
        "nome": "Mateus Silva",
        "cpf": "12345678909"
      },
      "solicitacao": {
        "especialidadeSolicitada": "Cardiologia",
        "cid10": "I10",
        "prioridade": "URGENTE"
      }
    }
  ]
}

POST /encaminhamentos/:id/aprovar

Aciona o algoritmo de agendamento automático. O atendente passa apenas o médico selecionado e a observação de balcão.

{
  "filaDestino": "CENTRO_ESPECIALIDADES",
  "nota": "Médico: Dr. Roberto Medeiros | Obs: Trazer exames antigos."
}

GET /pacientes/por-cpf/:cpf

Consulta se o paciente já possui cadastro no PEC municipal para preenchimento automático no Balcão.

{

  }
}

4. Modelagem de Dados no Backend

Os seguintes campos na tabela de encaminhamentos dão suporte à feature:

Campo Tipo Descrição
filaDestino ENUM('SUS', 'CENTRO_ESPECIALIDADES', 'CEO') Define a triagem/fila final para onde o encaminhamento aprovado foi destinado.
agendamentoPrevisto DATE (Nullable) A data reservada para a consulta (calculada pelo algoritmo backend no momento da aprovação/agendamento).
observacoesRegulacao TEXT (Nullable) Armazena as instruções do agendamento (nome do especialista, horário calculado, recomendações).
